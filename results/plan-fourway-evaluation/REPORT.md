# 계획서 평가셋 · 네 방식 비교

**학습을 추가로 실행하지 않았습니다.** 기존 GlyphWeave, Shikiji, 기존 두 모델의 점수순 결합, 이미 학습한 GlyphWeave의 결과를 동일 표본으로 비교했습니다.

대상 목록은 계획서에 적힌 **simpledic 대한검정회 누적 3,500자**입니다. 이전 한국어문회 3,500자/첫 세트 11,999개 평가와 표본·목록이 다르므로 이전 퍼센트와 직접 전후 비교하면 안 됩니다.

## 모든 모델에 동일한 간체→번체 후처리 적용

## 학습 모델에는 번체 변환을 붙이지 않는 경우

학습 모델은 이미 한국 목표 3,500자 표기로 출력합니다. 따라서 범용 간체→번체 변환이 오히려 일부 한국식 표기를 바꿀 수 있습니다. 공통 후처리 비교와 구분하기 위해 원본 출력 결과도 제시합니다.

| 평가 | 학습 모델 원본 Top-1 | 원본 Top-5 |
|---|---:|---:|
| Noto Sans 원본 | 99.86% | 100.00% |

## 결합 규칙

기존 GlyphWeave와 Shikiji 각각 전체 출력 목록에 softmax를 적용한 상위 5개를 가져옵니다. 글자 변환 후 동일 후보는 더 높은 점수 하나만 유지하며, 점수 내림차순으로 최종 5개를 선택합니다. 학습된 GlyphWeave는 이 결합에 포함하지 않았습니다. 가중치·온도·임계값 튜닝이나 평가 정답을 이용한 후보 선정은 하지 않았습니다.

## 동일성 및 한계

- 공개 모델 두 개는 73,987개 평가 이미지 모두를 실제 읽고 픽셀 해시를 확인해 실행했습니다. 학습 모델은 이미 계산된 after-predictions.csv를 재사용했습니다. 전 모델의 평가 ID·정답·순서 73,987개가 일치하며, 학습 모델 파일 SHA-256이 학습 결과 기록과 일치함을 확인했습니다.
- 학습 모델의 원본 Top-1·Top-5·macro Top-1은 기존 학습 보고서와 세 평가셋 모두 일치합니다.
- 고정된 픽셀 해시 기준 중복을 제거했습니다. 폰트 원본/변형/필기 점수를 합산하지 않았습니다. SCUT에 없는 428자는 필기 평가 불가이며 0점으로 넣지 않았습니다.
- 기존 GlyphWeave는 원본 7,247자 모델입니다. 학습 계획서의 학습 전 모델은 3,500자로 출력층을 재구성하고 신규 행을 초기화한 모델이므로 이 비교의 기존 GlyphWeave와 다릅니다.
- 학습 후 모델은 목표 목록에 맞춰 학습되고 출력이 제한되어 있습니다. 이 표는 실제 사용 방식 비교이며 출력층 학습의 순수 효과만 분리하는 실험은 아닙니다.
- 기존 모델과 Shikiji의 학습 데이터 중복/필기자 독립성은 검증하지 않았습니다. 학습 실험에서 정확한 학습·평가 픽셀 중복 0건을 확인했다는 기록은 유사 글씨·필기자 중복이 없다는 뜻이 아닙니다.
- CPU/GPU와 실행 방식이 다르므로 속도 순위는 비교하지 않습니다.
