# GlyphWeave + Shikiji 원시 softmax 점수순 합치기

한국어문회 1급 누적 3,500자 중 기존 첫 세트에 표본이 있는 3,158자 / 11,999개 필기에서 두 모델을 다시 실행해 점수를 수집했습니다. 나머지 342자에 대한 인식 정확도는 평가하지 못했습니다.

| 방식 | Top-1 | Top-5 |
|---|---:|---:|
| GlyphWeave 단독 | 68.89% (8,266) | 76.41% (9,168) |
| Shikiji 단독 | 54.45% (6,533) | 77.71% (9,325) |
| 두 모델 점수순 합치기 | 78.23% (9,387) | 91.08% (10,929) |
| 합친 후보 중 한국어문회 외 글자 제외 | 82.72% (9,925) | 93.02% (11,162) |

## 고정한 합치기 규칙

1. 두 모델 각각 전체 분류 목록에 대한 softmax를 계산하고 원래 상위 5개 후보와 점수를 가져옵니다. 상위 5개만 다시 정규화하지 않습니다.
2. 두 모델 모두 후보 글자에 OpenCC s2t와 Unicode NFC를 적용합니다.
3. 최대 10개 후보에서 같은 글자가 겹치면 더 높은 점수 하나를 남깁니다. 점수를 합산하거나 평균내지 않습니다.
4. 남은 후보를 점수 내림차순으로 정렬해 최종 상위 5개를 선택합니다. 같은 점수는 글자 순으로 정렬합니다.
5. 첫 합치기 결과는 한국어문회 외 후보도 그대로 포함합니다. 표의 마지막 행만 3,500자 밖의 후보를 제거한 보조 결과입니다. 어떤 조건에서도 각 모델의 원래 상위 5개 밖에서 후보를 추가하지 않습니다.

## 해석과 제한

- 두 모델 원래 후보를 최대 10개까지 모두 유지하면 정답 포함률은 93.71%입니다. 이는 Top-5가 아니며, 이번 점수 정렬이 달성할 수 있는 후보 풀의 정답 포함 상한을 보여줍니다.
- 후보 풀에 정답이 있었지만 점수순 상위 5개에서 탈락한 샘플은 315개입니다.
- 두 모델의 softmax는 서로 보정되지 않은 점수입니다. 이번 실험은 원시 점수를 직접 비교하는 고정 규칙을 실제 평가한 결과이며, 점수가 실제 정답 확률이거나 두 모델에서 같은 의미라는 보장은 없습니다.
- 별도 가중치/온도/임계값을 평가 데이터에 맞춰 조정하지 않았습니다. 기존 결과로 이미 관찰한 세트이므로 독립적인 최종 검증셋 결과는 아닙니다.
- 원본 재실행 후보와 앞선 후보의 차이는 validation.json에 기록했습니다.
- 모델 버전·출처, 필기 데이터, 한국어문회 목록 및 Unicode 표기 처리의 한계는 ../korean3500/REPORT.md와 각 모델 보고서와 동일합니다.

## 재실행

작업 폴더에서:
```sh
.venv/bin/python scripts/ensemble_scores.py glyph
.venv/bin/python scripts/ensemble_scores.py shikiji
.venv/bin/python scripts/report_ensemble.py
```

원시 점수는 glyph-scores.jsonl / shikiji-scores.jsonl, 병합 후보는 merged.csv / merged.jsonl, 요약은 summary.json에 저장했습니다.
