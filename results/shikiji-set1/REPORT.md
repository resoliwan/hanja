## 실행 방법과 검증

- 공개 모델: https://huggingface.co/kwadraten/shikiji, v0.0.2. 저장소 revision 및 공식 LFS SHA-256 대조 결과는 provenance.json에 보관했습니다.
- 모델 파일 143,951,632 bytes, 분류 대상 10,596종. ONNX Runtime CPUExecutionProvider, CPU 8스레드, batch 32로 실행했습니다.
- 이전 테스트와 동일한 원본 획 좌표를 동일한 렌더러로 128×128에 그렸습니다. 이후 공식 메타데이터에 맞게 160×160 RGB로 리사이즈하고 float32 [0,1] NCHW로 입력했습니다. 추가 평균/표준편차 정규화는 하지 않았습니다.
- 원본 비교는 정확한 Unicode 문자 일치이며 간체/번체·일본 신자체를 같은 글자로 취급하지 않았습니다. 분류 목록 전체에서 Top-5를 구했습니다.
- 학습 자료와 평가 자료의 중복 여부는 검증하지 않았습니다. 공식 모델 카드의 검증 정확도와는 데이터가 다릅니다.
- 시간은 전처리 포함 배치 처리량을 샘플당 환산한 값입니다. 이전 모델의 서로 다른 CPU/GPU 실행시간과 직접 속도 순위를 매기지 않습니다.

## 파일

- predictions.csv / predictions.jsonl: 전체 원본 후보
- predictions-s2t.csv / s2t-summary.json: 출력만 간체→번체 변환한 별도 결과
- summary.json: 정확도·지원 범위·미지원 글자
- provenance.json: 모델 revision, 크기, SHA-256

재실행: 작업 폴더에서 `.venv/bin/python scripts/run_shikiji.py`, 이어서 `.venv/bin/python scripts/report_shikiji.py`. 기존 JSONL 파일이 있으면 처리한 샘플 다음부터 재개합니다.
