# 절반 굵기 증강 100회 실험

상태: 완료

기존 B 모델 1회 가중치에서 시작해 총 100회까지 학습. 같은 원본 1,000개·분할·순서·학습률을 사용한다. 입력의 약 1/3에 획 폭 +6px 증강(기존 +12px의 절반), 그중 절반에는 blur radius 3을 추가한다. 정답은 증강된 획 폭을 보존한다.

원래 B.pt에는 optimizer 상태가 없어 최초 이어 학습 시 AdamW 상태만 새로 시작했다. 이후에는 모델·optimizer·완료 epoch·난수 상태를 매 epoch 원자적으로 저장해 재개할 수 있다. 기존 1회와 완전히 연속된 optimizer trajectory는 아니다.

평가도 절반 굵기로 수행하며 test-original-thickness.json에 기존 굵기 조건 평가를 함께 저장한다. 기존 100회 모델을 절반 굵기로 재평가한 baseline-half-thickness.json과 비교해야 학습 효과와 평가 난도 변화를 구분할 수 있다.

## 100회 단위 평가

|epoch|검증 Top-1|검증 Top-10|모니터링 Top-1|모니터링 Top-10|사진 변형 Top-1|사진 변형 Top-10|
|---|---:|---:|---:|---:|---:|---:|
|100|95.0%|100.0%|92.5%|98.5%|96.9%|100.0%|

검증은 기존 검증 원본 50개×6조건=300개로 최선의 체크포인트를 선택한다. 모니터링 평가는 원본 100개×6조건=600개다. 사진 변형은 앞서 관찰한 32개이며 사진 원본 두 글자는 별도로 저장한다. 반복 관찰하는 이 데이터들은 독립적인 최종 실사 정확도 추정용이 아니다.

best.pt 선택은 검증 Top-1, Top-10, Dice 순서다. 모니터링 평가 및 사진 변형 점수로 모델을 선택하거나 학습 설정을 바꾸지 않는다.

완료한 추가 학습 epoch: 99. 재시작은 같은 명령을 실행하면 last.pt에서 이어진다. 평가는 100/200/300/400/500에만 수행한다. 평가 도중 중단되면 재시작 시 해당 평가부터 다시 수행한다.

앱의 기존 한자 인식기는 고정되어 있고 배포 파일을 변경하지 않는다. 매 epoch progress.json과 last.pt, 매 100 epoch 평가 이미지·예측·모델을 저장한다. 비정상 수치나 실행 오류가 발생하면 상태를 error로 기록하고 중단한다.

실행: `PYTHONPATH=tools/handwriting .venv/bin/python -u -m photo_restoration.continue_capacity`
