# 一·二·三 시각적 매핑 평가

평가일: 2026-11-06. 평가자: 이 대화의 AI 어시스턴트.

SCUT 원본 좌표와 변환된 SVG 경로를 흑백 이미지 4장으로 그려 40개를 모두 직접 비교했다. 이미지에는 자동 채택 상태, 점수, 매핑 색을 넣지 않고 실제 입력 번호와 SVG 번호만 표시했다. 다만 같은 어시스턴트가 앞서 알고리즘 결과를 보았으므로 엄밀한 맹검이나 독립 인간 정답 평가는 아니다.

## 결과

| 항목 | 시각적 판단 |
|---|---|
| 자동 채택 27개 | 27개 모두 획 대응에 동의 |
| 보류 13개 중 일대일 매핑 가능 | 10개, 알고리즘의 제안 매핑에도 동의 |
| 나머지 보류 | 3개, 이어쓰기 또는 추가 입력 처리 필요 |
| 제안된 매핑 전체 | 37/37개에 동의 |

여기서 맞다는 것은 해당 SVG 획으로의 **대응**이 맞다는 뜻이다. 글자가 반듯하다거나 게임에서 반드시 정답으로 인정해야 한다는 판정이 아니다. 복잡한 한자에 대한 일반화 정확도나 독립 평가 정확도 100%로 해석할 수 없다.

## 발견한 문제

현재 보류 기준은 대응의 모호성과 필체의 모양 차이를 섞고 있다. 기울거나 짧고 끝이 되돌아가는 획도 전체 위치 관계를 보면 대응은 명확하다. 보류 10개는 답안지 생성 관점에서 과도하게 보수적이다. 반대로 크게 휜 一(trad5-17147)는 채택되어 있어, 모양 조건 자체도 균일한 필체 품질 기준은 아니다.

일대일 대응과 필기 품질을 별도 값으로 기록하는 것이 좋다. 대응 후보 사이의 차이와 전체 배치의 일관성을 중심으로 채택을 판단하고, 기울기/갈고리/되돌림은 품질 태그로 분리할 수 있다. 이 제안은 아직 알고리즘에 적용하지 않았다.
