# GlyphWeave 한국 한자 3,500자 학습·평가 계획서

작성일: 2026-11-04 (한국 시간)

## 결정 사항

- 대상은 simpledic의 대한검정회 누적 한자 3,500자만이다. 한글 음절, 영문, 숫자는 제외한다.
- 최초 실험은 **2번: 출력층만 학습**한다. 처음 제안했던 전체 미세조정은 후속 실험으로 보류한다.
- 기존 특징 추출 부분은 고정하고, 3,500자 분류층의 가중치와 점수 배율만 학습한다.
- 현재는 계획서와 데이터 분할안을 작성한 상태다. 이번 작업에서는 이미지 내용을 열지 않았고, 학습이나 인식 평가를 실행하지 않았다.

## 1. 입력과 출력의 의미

학습 자료의 정답 범위를 3,500자로 제한하고, 모델 출력도 이 3,500자로 고정한다. 입력층의 차원이 3,500인 것은 아니다.

| 항목 | 현재 공개 모델 | 이번 실험 모델 |
|---|---|---|
| 실제 입력 | 한 글자의 128×128 흑백 이미지 | 동일 |
| 내부 초기 처리 | 흑백 + 수평·수직 경사 채널 | 동일 |
| 분류 직전 특징 | 320차원 | 동일 |
| 출력 종류 | 7,247종: 한자 7,185자 + 영문·숫자 62종 | 목표 한자 3,500자 |
| 총 파라미터 | 7,820,044 | 6,621,004 |

3,500자 중 기존 모델에 있는 2,115자는 분류 가중치를 문자별로 복사한다. 없는 1,385자는 고정된 난수 시드로 초기화한다. 특징 추출 가중치는 공식 v1.0.0 체크포인트의 EMA 가중치를 가져온다. 출력층 점수 배율도 기존 값을 가져온다.

## 2. 네 가지 실험 정의

‘입력층’은 첫 Conv2d + LayerNorm으로 구성된 `stem`만 의미한다. 중간의 모든 특징 추출층을 입력층이라고 부르지 않는다.

| 번호 | 변경할 부분 | 학습 파라미터 | 고정 파라미터 | 상태 |
|---|---|---:|---:|---|
| 1 | 입력층(stem)만 | 2,040 | 6,618,964 | 보류 |
| 2 | 출력층(CosineHead)만 | 1,120,001 | 5,501,003 | **최초 실행 대상** |
| 3 | 입력층 + 출력층 | 1,122,041 | 5,498,963 | 보류 |
| 4 | 전체 미세조정 | 6,621,004 | 0 | 보류 |

출력층은 수치상 가장 작은 부분은 아니다. 그러나 신규 1,385자의 분류 가중치를 직접 학습할 수 있는 가장 단순한 출발점이다. 입력층만 학습하면 신규 출력 가중치는 무작위 초기값에 고정되므로 첫 실험으로 적합하지 않다.

독립 비교를 할 때는 네 실험 모두 동일한 3,500자 초기 체크포인트에서 출발한다. 2번 결과를 이어서 4번을 실행한다면, 그것은 별도의 ‘출력층 학습 → 전체 미세조정’ 실험으로 구분한다.

### 최초 실험의 학습·검증 배정안

AI-FREE를 문자별 픽셀 해시 그룹으로 나누고, 각 문자의 약 10%(내림)를 검증용으로 고정 선택한다. 그룹당 하나의 대표 이미지를 사용한다. 모든 AI-FREE 대상 문자는 중복 제거 후에도 최소 10개 이상이므로 이번 배정에서 빠지는 대상 문자는 없다.

| 용도 | 폰트 | AI-FREE | 합계 | 지원 문자 |
|---|---:|---:|---:|---:|
| 학습 | 82,440 | 144,087 | **226,527** | 3,500 |
| 검증 | 0 | 14,103 | **14,103** | 3,352 |

검증 선택 규칙과 선택된 sample_id는 `experiments/handwriting/results/hanja3500-training-plan/proposed-validation-sample-ids.txt`에 저장했다. 아직 기존 자료 목록의 usage를 검증용으로 변경하지 않은 배정안이다. 실제 학습 시작 시 이 파일의 ID를 학습에서 반드시 제외한다.

필기자 ID가 없어 이 검증셋을 ‘미학습 필기자 평가’라고 부르지 않는다. 원본의 변형 관계가 확인되면 같은 그룹으로 재배정해야 한다.

### 손글씨 자료가 없는 범위

- 학습 후보 AI-FREE가 없는 글자: **148자**. 이번 학습에서는 폰트 자료로만 학습한다.
- AI-FREE와 SCUT 양쪽에 없는 글자: **146자**.
- SCUT에 없는 글자: **428자**. 이번 최종 필기 평가에서 점수를 매길 수 없다.
- 폰트 평가는 모든 3,500자를 평가할 수 있으나, 손글씨 성능을 대신 증명하지 않는다.

CASIA 및 Shikiji 원본 이미지는 현재 데이터셋에 포함되지 않았다. 모델에 해당 글자가 있다는 이유로 학습 이미지를 확보했다고 세지 않는다.

## 4. 최초 실행 절차 — 출력층만 학습

### 4.1 동일한 초기 모델 만들기

1. 공식 체크포인트의 특징 추출 가중치를 로드한다.
2. `classes.txt`의 3,500자 순서에 맞춰 출력층을 재구성한다.
3. 기존 2,115자의 가중치 행은 복사하고, 신규 1,385자 행은 시드 42로 초기화한다.
4. 3,500자 초기 모델을 `initial-3500.pt`로 보관한다.
5. 이 시점의 결과를 **학습 전** 점수로 삼는다. 7,247자 원본 모델 점수와 구분한다.

### 4.2 고정 특징 추출

고정된 특징 추출 부분은 평가 모드로 두어 dropout·확률적 경로 제거를 끈다. 모든 특징 추출 파라미터의 gradient를 끈다.

출력층만 학습하므로 각 이미지의 320차원 특징을 한 번 계산해 저장하는 방식을 우선한다. 이렇게 하면 학습 회차마다 CNN을 다시 실행할 필요가 없다. 입력 이미지 처리에는 GlyphWeave 공식 전처리를 사용하며, 최초 실험에는 추가 무작위 변형을 적용하지 않는다. 이미 저장된 폰트 변형본은 그대로 사용한다.

특징 캐시는 학습·검증·평가를 별도 파일로 저장한다. 통계나 가중치를 평가 자료로 추정하지 않는다. float32 특징만으로 약 403 MB(약 384 MiB)가 필요하며 이미지 파일은 변경하지 않는다.

사용자의 ‘이미지를 읽지 말라’는 요청에 따라 현재 특징 추출은 실행하지 않았다. 실제 학습에서는 프로그램이 이미지 파일을 읽어야 하며, 시각적 전수검사와는 별개의 작업이다.

### 4.3 소규모 학습 설정

| 항목 | 최초 설정 |
|---|---|
| 학습 부분 | CosineHead의 weight와 log_scale만 |
| 고정 부분 | 입력층, 중간 특징 추출층, pooling, 정규화 등 나머지 전부 |
| 정답/출력 범위 | 동일한 3,500자 |
| 최적화 | AdamW |
| 출력층 학습률 | 0.001 |
| weight decay | 0.01, 점수 배율에는 적용하지 않음 |
| 손실 | Cross-entropy, label smoothing 0.05 |
| 특징 배치 크기 | 256 |
| 회차당 추출 | 35,000개: 문자별 10개, 복원 추출 |
| 최대 회차 | 10회, 최대 350,000개 특징 학습 |
| 중단 | 검증 문자별 평균 Top-1이 3회 연속 개선되지 않으면 조기 종료 |
| 체크포인트 | 검증 최우수, 마지막, 초기 모델을 각각 보관 |

문자별로 먼저 균등 추출한다. AI-FREE 학습 자료가 있는 글자는 필기 계열 75%·폰트 25% 확률로 출처를 선택한다. 필기 자료가 없는 148자는 폰트만 선택한다. 검증·평가 ID는 어떤 출처에서도 학습 추출 대상에 넣지 않는다.

전체 226,527장을 매번 모두 읽는 의미의 epoch가 아니다. 고정된 35,000개 추출 예산을 한 회차라고 부른다. 먼저 이 짧은 실험 결과만 보고, 무조건 대규모 학습으로 연장하지 않는다.

시간은 특징 추출이 대부분을 차지할 것으로 예상한다. 기존에 측정한 전체 모델 학습 속도 109장/초를 출력층 학습 시간으로 그대로 적용하지 않는다. 실제 특징 추출 초반 처리량을 측정한 뒤 종료 예상 시간을 갱신한다.

## 5. 학습 전후 평가 방법

### 평가셋을 분리해서 보고

| 평가 | 대상 | 사용 시점 |
|---|---|---|
| AI-FREE 검증 | 14,103장, 3,352자 | 학습 중 매 회차; 최우수 시점 선택 |
| Noto Sans 원본 폰트 | 3,500장, 3,500자 | 초기 모델 / 최종 선택 모델만 |
| Noto Sans 변형본 | 17,500장, 3,500자 | 초기 모델 / 최종 선택 모델만; 보조 견고성 지표 |
| SCUT 실제 필기 | 중복 제거 52,987장, 3,072자 | 초기 모델 / 최종 선택 모델만 |

SCUT의 기존 56,949장 전체 결과가 필요하면 별도 보조 표로 제시한다. 이번 주 비교는 중복 제거된 동일한 고정 샘플을 학습 전후에 사용한다. 폰트·필기·변형 점수를 합쳐 하나의 정확도로 만들지 않는다.

### 기록할 지표

- Top-1, Top-5.
- 문자별 정확도를 먼저 구한 뒤 평균한 macro Top-1.
- 8급~1급 최초 배정 급수별 정확도와 샘플 수.
- 기존 지원 2,115자 / 신규 1,385자별 점수. 각 평가셋에서 실제로 존재하는 문자 수와 샘플 수를 함께 표시한다.
- 폰트로만 학습한 148자 별도 점수. 필기 평가 샘플이 없는 경우 0점이 아니라 ‘평가 불가’로 표시한다.
- 문자별 오답과 혼동 후보, 학습 전후 변화(퍼센트포인트).

### 결과표 형식

| 실험 | 평가셋 | 학습 전 Top-1 / Top-5 / macro | 학습 후 Top-1 / Top-5 / macro | 변화 |
|---|---|---|---|---|
| 2. 출력층만 | Noto Sans 원본 | 미측정 | 미측정 | — |
| 2. 출력층만 | Noto Sans 변형 | 미측정 | 미측정 | — |
| 2. 출력층만 | SCUT 필기 | 미측정 | 미측정 | — |

나머지 1·3·4번 실험의 값은 실행하기 전까지 ‘미실행’으로 유지한다.

## 6. 후속 판단

최초 목적은 신규 문자가 출력되도록 학습되는지, 폰트에만 맞춰지고 필기 성능은 정체되는지, 기존 글자 성능이 유지되는지를 확인하는 것이다. 특정 목표 정확도를 사전에 보장하지 않는다.

검증 성능이 충분히 개선되지 않으면 그 원인을 확인한 뒤 전체 미세조정 또는 데이터 보강을 별도 실험으로 진행한다. 한 번 확인한 최종 평가 결과로 반복 설정을 고르면 그 평가셋은 개발용이 되므로, 이후 최종 성능 주장은 별도 잠금 평가 자료가 필요하다.

## 7. 완료 산출물

- `initial-3500.pt`, `head-only-best.pt`, `head-only-last.pt`.
- 3,500자 문자 매핑 및 원본 체크포인트/설정/시드/데이터 분할 해시.
- 학습·검증 회차 기록 및 실제 처리 시간.
- 학습 전후 평가 요약, 급수별/문자별 결과, 각 샘플의 Top-5 후보.
- 고정층이 학습 전후 변하지 않았는지와 학습·평가 ID가 겹치지 않는지 검증 기록.

현재 완료된 산출물은 이 계획서, 수량 집계 JSON, 검증 후보 ID 목록이다. 모델 파일과 학습 전후 점수는 아직 생성하지 않았다.
