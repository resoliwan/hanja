# SVG 획 기준 묶음 대응 v5

2026-11-06

## 목적과 변경

완성된 필기와 정답 글자의 SVG가 주어졌을 때 입력 구간별 정답 획을 만든다. 현재 검증 대상은 一·二·三·四·用이다. 실시간 인식기나 새 모델 학습을 구현한 작업은 아니다.

v4의 입력 구간별 가까운 SVG 투영 대신, 각 SVG 획에 대응하는 필기 구간 묶음을 만들고 전체 획의 배정을 함께 선택한다. 완성된 글자의 전체 정규화, 중앙 정렬 및 첫 획 정렬 가설 비교는 유지했다.

1. 원본 필기를 글자 전체 기준으로 정규화한다. 의미 있는 방향 변화에서 구간 경계를 만든다.
2. SVG 한 획의 후보로 연속된 필기 구간을 묶는다. 한 입력의 일부·전체, 두세 입력에 걸친 묶음을 지원한다. 기본 묶음 범위는 연속된 펜 입력 최대 3개이며 설정 가능하다.
3. 묶음 전체의 위치, 크기, 축별 이동, 경로 모양과 진행 방향을 비교한다. 경로 진행의 DTW는 순방향만 비교하고 방향 코사인에 절댓값을 취하지 않는다. 펜을 뗀 곳에는 가상의 잉크를 만들지 않는다.
4. 입력 내부를 잘게 나누거나 입력 여러 개를 묶는 경우 작은 비용을 추가한다. 이 비용은 분리/병합을 금지하지 않는다. 획순 역전도 작은 비용으로 취급해 공간 관계가 뚜렷한 비표준 순서는 허용한다.
5. 모든 SVG 획의 후보를 함께 선택한다. 동일 입력 구간의 중복 사용은 금지한다. 같은 펜 입력이라도 서로 다른 구간을 별도 SVG 획에 배정할 수 있다. 어느 획에도 속하지 않는 연결 구간은 남겨 둔다.

탐색은 SVG당 상위 24개 후보와 미대응 후보를 사용하고, 단계마다 상위 256개 조합을 남기는 빔 탐색이다. 전역 최적해를 보장하는 완전 탐색이 아니다. 5천 글자나 최대 33획의 실행 비용·성능은 아직 검증하지 않았다.

## 출력과 평가

정상 입력에서는 최선의 매핑을 항상 출력한다. 기존의 커버 45% 기준으로 결과 전체를 비우거나 보류하지 않는다. `mapped`는 예측 생성 완료이며 정답이라는 뜻이 아니다. 좌표가 없거나 잘못된 입력은 `invalid`로 명시한다.

- `mappings`: 입력 획 → SVG 획의 다대다 연결.
- `segment_mappings`: 원본 입력의 시작/끝 지점과 대응 획. 한 입력 내부에서도 서로 겹치지 않는 구간들이다.
- `target_groups`: SVG 획별로 선택한 입력 구간 묶음과 비용.
- `missing_target_strokes`: 입력 구간을 찾지 못한 SVG 획.
- `alignment_hypotheses`: 중앙/첫 획 정렬의 전체 목적함수 비교.

커버 범위는 진단 정보만 남긴다. 비용이나 커버율을 정답 확률로 표시하지 않는다. `training_usage=review_required`도 유지한다.

### 0·1 배정과 0~1 유사도

두 벡터를 함께 반환한다. 각각 길이는 항상 33이며 해당 글자의 실제 획 수는 `target_count`에 기록한다. 실제 획 번호를 넘는 칸은 0이다.

- `target_assignment`: 선택된 입력 묶음이 있으면 1, 없으면 0. 기존의 배정 결과다.
- `target_similarity`: 선택된 묶음의 `fit_cost`를 고정 기준으로 정규화한 값. 대응 묶음이 없으면 0이다.
- `target_groups[].similarity_score`: 같은 SVG 획의 점수. 연결 목록인 `mappings[].similarity_score`에도 그 묶음 점수를 함께 기록한다. 여러 입력이 한 묶음이면 묶음 전체 점수를 공유하며, 개별 입력만 평가한 점수가 아니다.

기본식은 `max(0, min(1, 1 - fit_cost / 0.60))`이다. 비용 0이면 1, 비용 0.30이면 0.5, 비용 0.60 이상이면 0이다. `similarity_cost_scale`로 기준 비용을 지정하며 양의 유한수만 허용한다. 이 기준은 보정 데이터로 학습한 값이 아니다.

획마다 독립적으로 정규화하므로 합이 1일 필요가 없고, 샘플별 최솟값/최댓값에 맞춰 가장 나쁜 입력까지 강제로 높은 점수로 만들지 않는다. 불필요한 미대응 선은 선택된 묶음의 유사도에 직접 가산/감산하지 않는다. 배정의 0·1은 유사도를 임계값으로 잘라 만든 값이 아니므로, 낮은 유사도여도 기존 알고리즘이 배정했으면 1일 수 있다.

이는 **유사도이며 정답일 확률, 다른 후보에 대한 상대 확률, 획의 색칠 비율이 아니다.** `score_normalization.calibrated_probability=false`로 의미를 함께 반환한다. 현재 변경은 완성된 필기 답안지 생성기에 점수를 추가한 것으로, 누적 입력에 대응하는 실시간 모델 구현은 아니다.

정답 주석과 비교할 때에는 필기 하나의 연결이 모두 맞으면 정답, 누락이나 추가 연결이 하나라도 있으면 오류다. 보류 범주는 없다. 구간 경계의 점 단위 정확도는 별도 정답 주석이 없으므로 평가하지 않는다.

## 결과

77개 원본 레코드에 실행했다. 사전 검토한 58개에서 중복을 제거한 54개로 같은 기준의 비교를 했다. 이번 평가 결과를 보고 가중치를 조정하지 않았다.

| 방법 | 전체 | 정답 | 오류 |
|---|---:|---:|---:|
| v4, 보류를 포함한 모든 후보 | 54 | 43 | 11 |
| v5, SVG 묶음 | 54 | 54 | 0 |

글자별 정답: 一 13/13, 二 14/14, 三 8/8, 四 9/9, 用 10/10. 기존 오류 11건 개선, 기존 정답 회귀 0건.

별도로 각 글자의 첫 평가 필기에서 가장 긴 입력을 둘로 나눈 5건, 첫 두 입력을 이어 쓴 4건도 구성해 9건 모두 연결 정답과 일치했다. 실제 사용자의 새로운 분리/연결 자료가 아니라, 원본 정답 관계를 유지하는 합성 동작 검사다.

동작 테스트 40개 통과(기존 30개 + v5 10개). 두세 입력을 한 획으로 묶기, 꺾인 획의 펜 분리, 이어쓰기와 연결선 제외, 비표준 획순, 중복 배정 방지, 방향 반전의 비용 변화, 원본 구간 위치, 잘못된 좌표를 확인했다. 전체 77건의 출력에서 서로 겹치는 배정 구간은 없었다.

## 남은 한계

54건은 구현에 참여한 AI가 시각적으로 검토한 개발 자료다. 독립적인 사람의 검수나 새로운 필기자에 대한 일반화 성능이 아니다. 이 점수로 자동 학습 정답의 신뢰성을 확정할 수 없다.

미주석 19건은 정확도 분모에 넣지 않았다. 이 중 다음 4건은 실제 출력에서 SVG 획을 하나씩 찾지 못했고, 四·用의 시각화에서도 남은 이어쓰기 문제를 확인했다.

- `trad1-10550` 四: 3번 획 누락.
- `trad2-18788` 用: 3번 획 누락.
- `trad2-19818` 用: 4번 획 누락.
- `trad5-00224` 四: 4번 획 누락.

연속 묶음 후보, 방향 변화에 의존하는 분할, 상위 후보 제한 때문에 복잡한 이어쓰기의 올바른 조합이 후보에 없거나 탐색에서 빠질 수 있다. 실제 이어쓰기/끊어쓰기의 구간 정답을 추가하는 것이 다음 검증 과제다. 전체 77건을 모두 정답으로 보고하지 않는다.

## 실행과 파일

```sh
.venv/bin/python tools/handwriting/build_stroke_answers.py --method target
.venv/bin/python tools/handwriting/evaluate_target_answers.py
.venv/bin/python -m unittest tools.handwriting.stroke_mapping.test_mapping tools.handwriting.stroke_mapping.test_segments tools.handwriting.stroke_mapping.test_guided tools.handwriting.stroke_mapping.test_targets
```

기본 생성 방식은 `target`이다. 기존 v2/v3/v4 방식과 결과는 보존했다.

- 구현: `tools/handwriting/stroke_mapping/target_matcher.py`
- 평가: `tools/handwriting/evaluate_target_answers.py`
- 결과: `experiments/handwriting/results/stroke-mapping-target-v5/`
- 정답 주석: 기존 v4의 `relation-reference.jsonl`을 수정 없이 사용한다. 평가 시 원본 궤적 해시도 확인한다.

## 8급 범위 실행

Simpledic의 대한검정회 8급 신출 30자 전체로 범위를 확장했다. 설정이나 비용 가중치는 변경하지 않았다. 기존 실험과 동일한 원본 SVG 30개의 획수가 사전 항목과 일치함을 확인했다. 사전에서 현재 사용 중인 생성 폰트 SVG와 원본 SVG의 경로는 각각 출처에 기록한다.

```sh
.venv/bin/python tools/handwriting/build_stroke_answers.py --method target --grade 8 --no-visuals
.venv/bin/python tools/handwriting/summarize_target_answers.py --directory experiments/handwriting/results/stroke-mapping-target-grade8-v5
```

550건(고유 궤적 513건): 모든 SVG 획 배정 487건, 획 누락 56건, 현재 정규화가 지원하지 않는 한 점/길이 0 획이 있는 입력 7건. 배정 완료를 정답이라고 간주하지 않는다. 카메라·새 이미지 판독 없이 좌표만 처리했으며 HTML/PNG도 생성하지 않았다. 상세 결과는 `stroke-mapping-target-grade8-v5/processing-report.md`에 있다.
